hyprMac

Predictable, tactile tiling that honors your native Mission Control Desktops.

Windows tile as you open them along their longer side. hyprMac works with the Desktops you already have in Mission Control. It doesn't replace them with virtual workspaces, and it doesn't need System Integrity Protection turned off. The layout engine is C++20 behind a C API, the macOS layer is Swift, and the config is sandboxed Lua.

INSTALLATION
$ git clone https://github.com/Codesmith28/hyprMac.git && cd hyprMac && make install
Run make preflight to audit system changes before installing. Fully reversible anytime with make uninstall.

Shortcut Action Notes
⌥1–9 Switch to Desktop N macOS Mission Control shortcut; hyprMac listens passively.

⌥⇧F Toggle Float / Tile Floats a tiled window or tiles a floating window.
⌥⇧R Flip Split Flips focused split orientation between horizontal & vertical.
⌥⇧C Center Window Centers the window on current display.
⌥⇧/ Open Cheatsheet HUD On-screen tutorial showing all active hotkeys.
Drag border Resize Split Drag tile edge by hand; split follows.
⇧-drop window Re-split Tile Drop window onto the side of another tile to partition it.
CONFIGURATION

~/.config/hyprmac/init.lua

Every key is optional; with no file you get defaults. Strict schema checking rejects unknown keys. Reloads automatically on save, from the menu, or via pkill -HUP -x hyprMac. 

config = {
    gaps = {
        inner = 8,   -- points between adjacent windows      (0 – 200)
        outer = 12,  -- points between windows and the edges (0 – 200)
    },
    split_ratio = 0.5, -- share of a split given to the existing window (0.1 – 0.9)
    resize_step = 5,   -- percent of a split per keyboard resize press (1 – 25)
    float = { min_width = 400, min_height = 300 }, -- smaller windows float (0 – 2000, 0 = off)
    osd_popup = true,  -- brief on-screen popup on window and Desktop actions
    keys = {           -- shortcuts (defaults shown)
        throw = "alt+shift", toggle_float = "alt+shift+f", switch = "alt",
        center_window = "alt+shift+c",
        focus_left = "alt+shift+h", focus_down = "alt+shift+j", focus_up = "alt+shift+k", focus_right = "alt+shift+l",
        move_left = "alt+shift+cmd+h", move_down = "alt+shift+cmd+j", move_up = "alt+shift+cmd+k", move_right = "alt+shift+cmd+l",
        rotate_split = "alt+shift+r",
        -- unbound by default: resize_left/down/up/right, equalize, toggle_zoom, move_display_next/prev, toggle_pause
    },
    rules = { ignore = {}, float = {} },           -- bundle ids: never managed / always floating
    smart_gaps = false,           -- one tiled window on a Space: zero gaps
    focus_follows_mouse = false,  -- hover focuses a window after ~120 ms
    -- displays = { ["Studio Display"] = { inner = 4, outer = 8 } },
    -- rules.float_title / rules.ignore_title = { "regex" }
    -- rules.desktop = { ["com.example.app"] = 3 }
}
ENGINE ARCHITECTURE

Swift + C++20 Core Design

Window events schedule a reconcile. The C++20 engine calculates target frames and writes them via Accessibility using one isolated serial queue per application. A hung application can never stall your desktop. 

HyprApp (Swift)           menu bar, onboarding, notifications
  └ HyprKit (Swift)       coordinator: one serial queue
      ├ HyprPlatform      Accessibility, Spaces, hotkeys, window writes
      └ hyprcore (C++20)  BSP layout, gaps, Lua config
                          C API: core/include/hypr/hypr_core.h
PREREQUISITES

System Requirements

  • macOS 14 or later. Tested on macOS 27.2, Apple Silicon.
  • Command Line Tools (xcode-select --install).
  • Displays have separate Spaces enabled in System Settings.
  • Stage Manager is off. make install turns it off.
  • ⌥1–⌥9 bound to "Switch to Desktop N" in Mission Control.
BUILD TARGETS

Terminal Commands

  • make — Build core engine and build/hyprMac.app
  • make run — Run the app in foreground without installing
  • make test — Non-privileged test suite
  • make preflight — Audit system mutations without changing anything
  • make install — Install to ~/Applications and start at login
  • make update — Rebuild, update ~/Applications/hyprMac.app, and reload
  • make uninstall — Cleanly undo all modifications
  • make verify-rollback — Compare system state against pre-install snapshot
